### 📝 observer note

- SKILL.md 行数 110 は tdd (380) の 1/3.5。最小限構成で「判断マトリクス」「出力形式テンプレート」に相当する部分が薄い
- 判断マトリクス（仕様×テスタビリティ）のような構造が **無い** 点は tdd と大きく異なる。「Phase 1 で再現不能なら修正禁止」のみが判断ルール。シナリオD（本番のみ再現）で subagent がどう振る舞うかで穴が見える可能性あり
- 「デバッグ記録テンプレート」は出力形式テンプレートに相当するが、シナリオBの「試したこと」節活用など運用フローは未記述
