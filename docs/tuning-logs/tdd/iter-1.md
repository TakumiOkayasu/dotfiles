## 次の修正案（iter 2 の 1 テーマ）

**採用**: A-2「既に一般化済みの実装で即 PASS するテストの扱い」を SKILL.md に追記

**理由**:
- 3 シナリオ全てで精度 100% だが「裁量補完」が多く、特に A-2 は **RED 確認の鉄則と正面から衝突する** 唯一の構造的穴
