# Rules Required Fragment

Before editing, running mutating commands, reviewing, or proposing implementation details, read and apply rules from:

1. project-local `.codex/rules/*.md`
2. repo-local `codex/rules/*.md`
3. global `~/.codex/rules/*.md`

If `rules-inject.sh` injected full rule contents into context, treat those contents as read. If not, explicitly read the files. Do not assume rules are automatically loaded.
