# UI Operation (UI操作系)

ユーザーの操作パターンで壊れるケース。

## パターン一覧

### UO-01: Tab順序の論理性

- 攻撃: フォーム画面でTabキーを連打して全フィールドを巡回
- 検証: 視覚的なレイアウト順序とTab順序が一致するか。隠し要素にフォーカスが当たらないか
- 壊れ方: Tab順序が飛ぶ、非表示要素にフォーカスが当たり入力不可
- スクショ箇所: フォーカス遷移の各ステップ
- 嫌度: ★★★☆☆

### UO-02: Enterキーによる意図しないsubmit

- 攻撃: テキストフィールドでEnterキー押下
- 検証: 意図しないフォーム送信が起きないか。検索フィールドなら検索実行されるか
- 壊れ方: 未入力のまま送信、確認ダイアログなしで登録
- スクショ箇所: Enter押下前後
- 嫌度: ★★★★☆

### UO-03: コピー&ペーストの挙動

- 攻撃: 他アプリからリッチテキスト(Excelセル、Word文字装飾付き)をペースト
- 検証: プレーンテキストとして貼り付くか。HTMLタグが混入しないか
- 壊れ方: hidden style属性混入、改行コードの違い(CRLF/LF)
- スクショ箇所: ペースト後の入力欄
- 嫌度: ★★★☆☆

### UO-04: ドラッグ&ドロップのエッジ

- 攻撃: D&D対応UIで、同じ場所にドロップ / 許可されない場所にドロップ / D&D中にEsc
- 検証: 元の位置に戻るか。エラーにならないか
- 壊れ方: 要素が消える、順序がおかしくなる
- スクショ箇所: D&D前後
- 嫌度: ★★★☆☆

### UO-05: 右クリックメニューの干渉

- 攻撃: カスタムコンテキストメニューがある要素でブラウザデフォルト右クリック
- 検証: カスタムメニューが正しく表示されるか。ブラウザメニューが出ないか
- 壊れ方: 両方のメニューが重なる、カスタムメニューが画面外
- スクショ箇所: 右クリック時
- 嫌度: ★★☆☆☆

### UO-06: キーボードショートカットの競合

- 攻撃: Ctrl+S(保存)、Ctrl+Z(Undo)、Ctrl+A(全選択)等のブラウザ標準キー
- 検証: アプリ独自ショートカットがブラウザと競合しないか
- 壊れ方: Ctrl+Sでページ保存ダイアログが出る
- スクショ箇所: ショートカット押下時
- 嫌度: ★★☆☆☆

### UO-07: フォームの自動補完干渉

- 攻撃: ブラウザの自動入力(住所、メール等)を有効にしてフォーム入力
- 検証: 自動補完がフィールドと正しくマッピングされるか。autocomplete属性が適切か
- 壊れ方: 名前欄にメールアドレスが入る、パスワードが露出
- スクショ箇所: 自動補完ポップアップ表示時
- 嫌度: ★★★☆☆

### UO-08: 複数選択の矛盾

- 攻撃: 全選択 → 1件解除 → 全選択 → 一括削除
- 検証: 選択件数表示が正しいか。一括操作の対象が期待通りか
- 壊れ方: 解除したはずの1件も削除される、件数表示がズレる
- スクショ箇所: 選択状態の各ステップ
- 嫌度: ★★★★☆

### UO-09: スクロール位置の保持

- 攻撃: 長い一覧を下までスクロール → 詳細画面 → ブラウザバック
- 検証: 一覧画面のスクロール位置が復元されるか
- 壊れ方: 先頭に戻される、読み込み中の空白が表示
- スクショ箇所: バック後の一覧画面
- 嫌度: ★★★☆☆

### UO-10: モーダル外クリック・Escキー

- 攻撃: モーダルダイアログ表示中に背景クリック、Escキー
- 検証: モーダルが閉じるか。未保存の入力がある場合に確認ダイアログが出るか
- 壊れ方: 入力内容が消える、モーダルが閉じない
- スクショ箇所: モーダル表示時
- 嫌度: ★★★☆☆
