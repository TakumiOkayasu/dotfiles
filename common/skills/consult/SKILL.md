# Consultation

通常の問題整理、trade-off判断、推奨はモデル自身の通常推論で行う。本skillは、比較と決定記録を独立成果物として残す必要がある場合だけ使う。

## 使用条件

次のいずれかをユーザーが明示的に求めた場合に使用する。

- 複数の実質的な選択肢を比較する
- 方針決定を記録する
- 実装者へ渡すhandoffを作る

選択肢が実質1つしかない場合、架空の案を増やさない。公式documentや既存codeを読めば判断できる場合、通常の調査として処理する。

## 出力

必要な項目だけを使う。

```markdown
## 問題
- 目的:
- 制約:

## 選択肢
- 案:
- trade-off:
- evidence:

## 決定
- 採用:
- 理由:
- 未確認事項:

## 引き継ぎ
- Tasks:
- Files:
- Done when:
```

## 禁止事項

- skillを使うために選択肢を捏造する
- 通常の設計判断へ自動適用する
- 調査前に形式だけ埋める
- 方針決定と外部writeを同一視する
