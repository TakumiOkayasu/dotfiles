# Consult(Claude API壁打ち)

## 📋 実行前チェック(必須)

### このスキルを使うべきか?
- [ ] 実装中に判断が必要になった?
- [ ] 別の視点からの意見が欲しい?
- [ ] 複雑な問題で行き詰まっている?
- [ ] 設計方針を確認したい?

### 前提条件
- [ ] `ANTHROPIC_API_KEY` が設定されているか?
- [ ] `consult` コマンドが使用可能か?
- [ ] 質問を具体的に言語化できているか?
- [ ] 少なくとも1つは解決策を試したか?

### 禁止事項の確認
- [ ] 「何が分からないか分からない」状態ではないか?
- [ ] 公式ドキュメントを確認したか?
- [ ] 漠然とした質問になっていないか?

---

## 🚨 鉄則

**「AとBで迷っている」まで具体化してから相談。**

---

## トリガー

### 手動トリガー
- ユーザーから「相談して」「APIに聞いて」「Opusに相談して」
- 設計判断で迷っている時
- エラーの根本原因が分からない時

### 自動トリガー(auto-consultation経由)
- 同じエラーが2回発生した時
- 解決策が見つからず行き詰まっている時

---

## 実行方法

### 基本

```bash
# Sonnetに相談(デフォルト、~$0.02/query)
consult "JWTの保存場所はlocalStorageとhttpOnly Cookieどちらが適切?"

# Opusに相談(複雑な問題、~$0.06/query)
consult -m opus "マイクロサービス間の認証設計について相談"

# Haikuに相談(シンプルな確認、~$0.005/query)
consult -m haiku "この命名は適切?"

# パイプで入力
cat error.log | consult "このエラーの原因は?"
```

### オプション

```bash
# モデル指定
consult -m sonnet "質問"  # デフォルト
consult -m opus "質問"    # 複雑な問題
consult -m haiku "質問"   # シンプルな確認

# トークン数指定
consult -t 4096 "短い回答で"
```

## 相談テンプレート

### 設計判断

```bash
consult "
[判断が必要な点]: 状態管理にReduxを使うべきかContext APIで十分か

[現状]:
- 中規模SPAアプリケーション
- 状態の種類: ユーザー情報、カート、UI状態

[選択肢]:
A. Redux - 実績あり、DevTools便利、ボイラープレート多い
B. Context API - シンプル、追加依存なし、再レンダリング懸念

[制約]:
- チームにRedux経験者が少ない
- パフォーマンス要件は厳しくない
"
```

### エラー解析

```bash
consult "
[エラー]: TypeError: Cannot read property 'map' of undefined

[コード]:
\`\`\`javascript
const items = data?.items;
return items.map(item => <Item key={item.id} {...item} />);
\`\`\`

[試したこと]:
1. optional chaining追加 → 変化なし
2. console.logでdata確認 → 非同期で遅れて到着

[仮説]:
初回レンダリング時にdataがundefined
"
```

### 複雑な問題(Opus推奨)

```bash
consult -m opus "
[相談]: マイクロサービス間の認証・認可設計

[要件]:
- 5つのサービス間で認証情報を共有
- 各サービスで独自の認可ロジックあり
- 外部IdP(Auth0)を使用

[検討中のアプローチ]:
A. JWT伝播方式
B. API Gateway一括認証
C. サービスメッシュ(Istio)

[懸念点]:
- トークン失効時の伝播
- サービス間通信の認証
"
```

---

## 結果の活用

1. **回答を検証** - 提案された解決策を実際に試す
2. **記録** - 重要な相談結果は `claude_tmp/consultation/` に保存
3. **フィードバック** - うまくいった/いかなかったを記録

---

## 🚫 禁止事項まとめ

- 何も試さずに相談
- 「何が分からないか分からない」状態で相談
- 公式ドキュメントを確認せずに相談
- 漠然とした質問(「どうすればいい?」)
- Opusの乱用(コスト注意)
