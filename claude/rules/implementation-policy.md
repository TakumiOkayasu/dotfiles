# Implementation Policy

**車輪の再発明禁止。技術選定・ライブラリ利用・データアクセスの方針。**

## 基本原則

| ルール | 内容 |
| -------- | ------ |
| 既存優先 | 標準ライブラリ/定評OSS/採用済みフレームワークで解決できるなら自前実装禁止 |
| 自前実装の条件 | 「なぜ既存で不可なのか」を明示し承認を得る |
| 再発明禁止対象 | 汎用ユーティリティ (配列/オブジェクト操作, 日時, UUID, 乱数, エンコード, 正規表現マッチ等) |
| 実行時パフォーマンスの優先 | **最悪でも**線形時間、線形対数時間で終わらせる |

## 依存管理

| 項目 | ルール |
| ------ | -------- |
| 追加前確認 | 新規ライブラリ追加前に**既存依存で代替可能か確認**。代替不可の場合のみ追加 |
| 選定基準 | 定評 (利用実績) + メンテ状況 (6ヶ月以内コミット) + ライセンス (MIT/Apache/BSD系) を確認 |
| バージョン固定 | lockfile (`package-lock.json`, `poetry.lock`, `Cargo.lock` 等) は**必ずコミット**。`latest`/ワイルドカード指定禁止 |
| 脆弱性確認 | 依存追加・更新時に脆弱性スキャン (npm audit, pip-audit等) を実行 |

## 必須経由

| 領域 | ルール |
| ------ | -------- |
| **DBアクセス** | ORM経由を原則 (例外は後述) |
| **スキーマ変更** | マイグレーションツール経由必須。本番DDL直接実行禁止 |
| **ロギング** | 本番コードはロギングライブラリ経由 (`print` / `console.log` / `echo` の直接使用禁止)。個人ワンショット/使い捨てスクリプトは対象外 |
| **バリデーション** | 入力検証は定評ライブラリ (zod / pydantic / joi / valibot 等) を使用。自前if羅列禁止 |
| **暗号・ハッシュ** | **絶対に自前実装禁止**。言語標準または定評ライブラリのみ使用。アルゴリズム選定は公式推奨に従う |
| **HTTPクライアント** | プロジェクト内で1つに統一。混在禁止 |
| **設定値** | 環境変数または設定ファイルで外部化。コード内ハードコード禁止 |

## ORM 例外条件 (生SQL許可シナリオ)

| 許可シナリオ | 条件 |
| ------------ | ----- |
| バルク処理 | パフォーマンス計測結果を根拠に提示 |
| 複雑な集計 (CTE/window関数等) | ORMで表現困難なことを示す |
| DB固有機能 | PostgreSQL固有型・全文検索等、移植性を捨てる判断を明示 |
| 読み取り専用レポート | ビュー定義または生SQL、**レビュー必須** |

**共通条件**:

- プリペアドステートメント必須 (SQLインジェクション対策)
- 監査可能な形でコミット (レビュー対象として明示)
- 理由をコメントまたはPR本文に記載

## 禁止事項 (絶対)

| 禁止 | 理由 |
| ------ | ------ |
| 暗号・ハッシュの自前実装 | セキュリティリスク。専門家設計のライブラリを使う |
| 本番DDL直接実行 | 履歴管理不能 / ロールバック不能 |
| 文字列連結によるSQL組み立て | SQLインジェクション |
| `print` / `console.log` 等の直接使用 (本番コード) | ログレベル制御不能 / 構造化困難 |
| 設定値のハードコード | 環境ごとの切替不能 / 秘密情報漏洩リスク |
| `latest` / ワイルドカード依存指定 | 再現性喪失 |

## 使用例

```python
# ❌ 禁止: 自前ハッシュ・生SQL・print
def save_user(name, password):
    hashed = hashlib_custom(password)  # 自前ハッシュ
    db.execute(f"INSERT INTO users VALUES ('{name}', '{hashed}')")  # SQLi
    print(f"saved {name}")  # 直接print

# ✅ 正しい: 定評ライブラリ + ORM + logger
def save_user(name: str, password: str) -> None:
    hashed = bcrypt.hashpw(password.encode(), bcrypt.gensalt())
    User.objects.create(name=name, password_hash=hashed)
    logger.info("user saved", extra={"name": name})
```
