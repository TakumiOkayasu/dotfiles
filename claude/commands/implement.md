# Implementation Guide

機能を実装する(TDDスタイル)

## 引数
$ARGUMENTS に実装する機能の説明が渡されます。

## 実行手順

### Phase 1: 理解
- 要件を整理して箇条書きで確認
- 影響範囲の特定
- 既存コードとの整合性確認

### Phase 2: テスト設計 (RED)
- 期待する振る舞いをテストで表現
- エッジケースも考慮
- テストが失敗することを確認

### Phase 3: 実装 (GREEN)
- テストを通す最小限の実装
- シンプルさを優先
- 動くことを確認

### Phase 4: リファクタリング (REFACTOR)
- コードの改善(テストは通ったまま)
- 重複排除、命名改善、構造整理
- パフォーマンス考慮

### Phase 5: 報告
- 実装サマリー
- 変更ファイル一覧
- 次のステップ提案
