# Task Executor

タスクファイルを読み込んで実行する

## 指示
指定されたタスクファイルを読み込み、記載された作業を実行してください。

## 引数
$ARGUMENTS にタスクファイルのパスが渡されます。
例: `/task tasks/add-user-validation.md`

## 実行手順

1. **タスクファイル読み込み**
   - `$ARGUMENTS` で指定されたファイルを読む
   - ファイルが存在しない場合は `tasks/` 内のファイル一覧を表示

2. **内容確認**
   - タスクの目的、スコープ、制約を確認
   - 不明点があれば実装前に質問

3. **実装計画の提示**
   - 変更対象ファイルの一覧
   - 実装順序の概要
   - 確認後に実装開始

4. **段階的実装**
   - 小さな単位でコミット可能な状態を維持
   - 各ステップで動作確認

5. **完了報告**
   - 実施内容のサマリー
   - 次のアクション(テスト実行、レビュー依頼等)を提案
