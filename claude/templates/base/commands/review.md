# Code Review

## 引数
$ARGUMENTS にレビュー対象を指定(省略時は直近の変更)

## レビュー観点

### 1. 正確性
- ロジックは正しいか
- エッジケースは考慮されているか
- エラーハンドリングは適切か

### 2. 設計
- 責務は適切に分離されているか
- 依存関係は妥当か
- 拡張性は考慮されているか

### 3. パフォーマンス
- 不要な処理はないか
- メモリ効率は良いか
- N+1問題などはないか

### 4. 可読性
- 命名は明確か
- コメントは適切か
- 複雑すぎる箇所はないか

### 5. テスト
- カバレッジは十分か
- テストは意味のある検証をしているか

## 出力形式

### Critical (修正必須)
- [ファイル:行] 問題の説明

### Warning (修正推奨)
- [ファイル:行] 問題の説明

### Suggestion (任意)
- [ファイル:行] 改善提案

### Good Points
- 良かった点
